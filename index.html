Fields untuk Collection "cs_daily_reports"

    

      
Dalam PocketBase Admin UI → Collections → New collection (type: Base, nama: cs_daily_reports) → tambah fields berikut (hanya wa1 & em1 digunakan untuk Syria Care, lain-lain dibiarkan 0):

      
report_date   date      required
staff_name    text      required
shift         text
wa1_masuk     number    default 0
wa1_engaged   number    default 0
wa2_masuk     number    default 0
wa2_engaged   number    default 0
wa3_masuk     number    default 0
wa3_engaged   number    default 0
wa4_masuk     number    default 0
wa4_engaged   number    default 0
em1_masuk     number    default 0
em1_engaged   number    default 0
em2_masuk     number    default 0
em2_engaged   number    default 0
notes         text

API Rules (Settings > cs_daily_reports > API Rules):
  List/Search rule   : (kosongkan untuk public, atau set auth rule)
  View rule          : (kosongkan untuk public)
  Create rule        : (kosongkan untuk public)
  Update rule        : (kosongkan untuk public)
  Delete rule        : (kosongkan untuk public)

Nota: rule kosong ("") = sesiapa boleh akses tanpa login.
Kalau nak lock down, isi rule dengan syarat auth (cth: @request.auth.id != "").
